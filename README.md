# Pulseboard Collector releases

Repositorio público de distribución de Pulseboard Collector para Windows.

Aquí se publican únicamente:

- El instalador autocontenido `Pulseboard-Collector-Setup-x64.exe`.
- Su checksum SHA-256.
- Un manifiesto con versión, arquitectura y estado de firma.

El código fuente se mantiene en un repositorio privado. Descarga siempre la [última versión](https://github.com/jesusfrguz/pulseboard-releases/releases/latest).
