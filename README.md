# TokGauge Collector releases

Repositorio público de distribución de TokGauge Collector para Windows.

Aquí se publican únicamente:

- El instalador autocontenido `TokGauge-Collector-Setup-x64.exe`.
- Su checksum SHA-256.
- Un manifiesto con versión, arquitectura y estado de firma.

El código fuente se mantiene en un repositorio privado. Descarga siempre la [última versión](https://github.com/jesusfrguz/tokgauge-releases/releases/latest).
